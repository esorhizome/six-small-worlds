## Clip 3 · Twist — "One symbol changes the whole forest"

**Hook line (≤ 8 words):** One symbol changes the whole forest.
**Length:** ~30 s, loop-closed. The replayable clip — invite duets/stitches.

| Seconds | Shot | Text on screen |
|---|---|---|
| 0–3 | The classic plant, whole. | "this is one rule" |
| 3–10 | Zoom into the rule string `X → F+[[X]-X]-F[-FX]+X`; cursor changes a single `-` to `+`; run: a visibly different species. | "changed one symbol" |
| 10–18 | Back to the rule; change the final `X` to `F`; run: another species. Side-by-side strip of all three. | "one symbol. new species." |
| 18–26 | The rule becomes a *list* of three options; `pick_random()` highlighted; run three times fast — three different plants. | "now it rolls dice" → "every plant unique" |
| 26–30 | A strip of six sibling plants slides past; the first plant returns exactly as the loop restarts. | "what did you get?" |

**Caption:** Same grammar, different dice — that's why no two ferns match.
Change one symbol in the rule, run it, and stitch this with what grew.
**Hashtags:** #godot #lsystem #proceduralart #creativecoding
**CTA:** duet/stitch invite only — "what did you get?"
