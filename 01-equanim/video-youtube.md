# World 1 · equanim — long-form scripts (E01–E03)

*Three episodes of the [long-form course](../00-course/longform-youtube.md),
one per lesson in this folder. Format per STYLE.md: cold open with no logo,
beats table (timecode · on screen · spoken), B-roll cues in italics, end card
in the final 15 seconds. Spoken register: shorter sentences than the written
lessons — these are said aloud. Timecodes assume live typing and run pauses;
speech target 12–18 minutes per episode.*

Before recording each episode: the lesson's milestone files open in tabs, the
starter file rehearsed once, the finished visual captured for the cold open.
